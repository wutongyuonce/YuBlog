# 版心缩窄：SPEC 与设计

## SPEC

### 背景与目标

桌面索引页原版心上限为 1072px，首页左栏 752px、右栏 264px、栏距 56px；顶栏与版心对齐。目标是让索引页桌面排版约缩窄五分之一，留出更舒展的两侧空白。文章页的标题和正文保持原有阅读宽度。

### 范围与行为

- 首页及标签、归档、项目、关于、友链页共用的索引版心上限为 858px。两栏时，主栏 602px、右栏 212px、栏距 44px；右栏内容随栏宽自然换行，固定定位时仍与该栏对齐。
- 博客列表卡片内部，文字列占可分配宽度的 62.5%（原为 60%），配图列占 37.5%；卡片间距、主栏、右栏和版心宽度保持不变。
- 归档页每篇文章的标签在标题下方单独成行，完整换行显示，字号更小、颜色更淡。
- 全站顶栏的内容和底边线与索引版心左右边界对齐；文章页顶栏同样使用该边界。导航项、社交入口、搜索和主题切换仍可见、可用。
- 文章页标题与正文在常规桌面 / 1280px 以上分别保持 65ch / 70ch 的原有阅读宽度；其他 `StandardLayout` 页面沿用较窄的通用宽度。桌面目录仍留在正文外侧，栏宽不变，各级标题超出单行时完整换行；移动目录仍可使用。
- 在版心装不下两栏时沿用现有单栏规则；更窄的屏幕继续使用可用视口宽度和现有内边距，不强制再缩 20%。顶栏空间不足时分行展示品牌、工具和导航，不允许水平溢出或遮挡入口。正文中的完整 URL 也应在窄屏内断行。

### 不变量与边界

| ID | 义务 | 验收证据 |
| --- | --- | --- |
| W1 | 宽屏索引页的版心、左右栏和栏距约为旧值的 80%，顶栏左右边界一致 | 测量首页与其他索引页的容器和顶栏矩形 |
| W2 | 文章标题、正文共用原有阅读宽度，桌面目录不压到正文；顶栏仍与索引版心对齐 | 测量有图、无图文章的标题/正文/目录与顶栏 |
| W3 | 临界宽度及手机上无页面水平溢出，导航和右栏内容可读可操作 | 1099px 断点两侧、导航断点两侧、390px / 320px 视口与长 URL 文章检查 |
| W4 | 硬刷新和 ClientRouter 导航后的布局一致，右栏锁定后宽度和位置跟随实际列宽 | 两种进入方式及滚动检查 |
| W5 | 博客列表文字列略宽，配图仍完整位于卡片内；单栏断点仍正常 | 首页、标签页桌面卡片列宽和手机单栏检查 |
| W6 | 归档文章的标题与标签上下排列，标签完整显示且视觉层级低于标题 | 检查有标签、长标签和无标签的文章行 |
| W7 | 桌面 TOC 在原栏宽内完整换行，长目录仍可纵向滚动 | 检查多级长标题文章及 1200px 目录边界 |

这次只改布局，不改字号、内容、导航项目、筛选与分页逻辑。视觉上的“五分之一”针对桌面容器上限；受视口约束时以可读性为先。无数据失败、取消或并发状态变化；资源开销仍为现有 CSS 布局与右栏测量。

## 设计

| 义务 | Authority 与界面 | 调用方 / 验证 |
| --- | --- | --- |
| W1、W3 | `src/styles/main.css` 的版心宽度变量；`public/shell.css` 的顶栏和两栏网格 | `NavBar`、`BlogIndexLayout` 和六个索引页；浏览器测量 |
| W2 | `src/styles/main.css` 的 `--blog-article-width`；`src/styles/prose.css` 和 `DesktopAside` 共同消费 | `StandardLayout`、`RenderPost`；有图/无图文章测量 |
| W4 | `BlogIndexLayout` 继续测量真实右栏列宽，`public/shell.css` 消费其定位变量 | 右栏锁定测试与浏览器滚动检查 |
| W5 | `ListItem.astro` 的卡片网格比例 | 首页与标签页共用卡片；浏览器测量 |
| W6 | `public/shell.css` 的归档网格与标签样式 | `ArchiveView` 的有标签和无标签文章 |
| W7 | `src/styles/main.css` 的 TOC 标题换行；`TocSidebar` 继续管理目录滚动 | `DesktopAside` 的栏宽计算不变；长标题浏览器测量 |

沿用现有两栏、单栏和目录滚动机制。桌面导航缩小链接的横向内边距；959px 以下采用两行，600px 以下将品牌、工具、页面导航分成三行。CSS 媒体查询仍与 `blog-sidebar.js` 的 1099px 单栏阈值保持一致。`src/styles/prose.css` 负责正文长链接的窄屏断行。

### 验证结果

- `pnpm check`：84 个文件，0 error / warning / hint；`pnpm lint`、`pnpm format`、`pnpm test`：均通过，测试 30 项无跳过。
- `pnpm build`：44 个静态页面生成成功，Pagefind 索引 37 篇文章。
- 生产预览中，1440px 首页顶栏与索引版心同为 858px，主栏 602px、右栏 212px；滚动锁定后右栏仍为 212px。首页→文章→标签的 ClientRouter 导航后边界和壳层样式保持一致。
- 960/959px 导航断点、1100/1099px 两栏断点、390/320px 手机宽度均无页面水平溢出。文章有图和无图标题、正文在 1440px 视口同为约 707px，在 1200px 视口同为约 656px；390px 视口同为 334px。桌面 TOC 与正文保持至少 56px 间距，宽表格保留局部横向滚动。
- 首页与筛选后的标签页卡片在 1440px 视口内，文字列约 359px（原约 344px）、配图列约 215px；390/320px 仍为单栏且无水平溢出。
- 归档页标签与标题分行，长标签在主栏内换行；OpenViking 文章的多级长目录标题在 1440px 和 1200px 视口内完整换行，目录仍可独立滚动。
- 复审修复了正文完整 URL 在 320px 视口造成的 52px 页面溢出；重新构建后的 OpenViking 文章在 320px 和 390px 均无水平溢出。
