# 博客上下篇与随便逛逛 SPEC

文稿详情页与文稿列表的导航契约：上一篇／下一篇邻接、随便逛逛随机跳转，以及列表页固定顶行。页面总行为见 [站点行为 SPEC](./站点行为%20SPEC.md)，集合排序权威见 `src/utils/data.ts` 的 `getSortedPosts`。

## 1. 背景与目标

读者在读完一篇文稿后，需要低摩擦地进入相邻文稿或任意另一篇；在文稿列表任意分页上也能一键「随便逛逛」。交互保持 YuBlog 稀疏、轻量的壳层气质，不引入喧闹按钮或额外分页状态。

## 2. 产品规则（已确认）

### P1：详情页导航行

- 位置：正文与 `cd ..` 之后、评论区之前（`after-content` 槽，排在 Giscus 前）。
- 文案：`上一篇`｜`随便逛逛`｜`下一篇`。
- 边界：有序列表中**最新**一篇（数组下标 0）不显示「上一篇」；**最旧**一篇不显示「下一篇」；中间三枚齐全。仅一篇已发布（或当前可见）文稿时，「随便逛逛」亦不显示。

### P2：顺序与邻接语义

与文稿列表、`getSortedPosts` 完全一致：

1. `pubDate` 降序（新 → 旧）
2. 同日按 `id.localeCompare` 升序

中文博客常见约定（本站采用）：

| 标签 | 含义 | 在降序数组中的位置 |
| --- | --- | --- |
| **上一篇** | 更旧的一篇 | 当前下标 + 1 |
| **下一篇** | 更新的一篇 | 当前下标 − 1 |

### P3：随便逛逛

- 详情页：从**当前可见集合**中随机一篇，**排除当前**。
- 列表页：从同一集合中随机任意一篇。
- 集合与详情／列表一致：生产环境排除草稿；开发预览与 `getFilteredPosts` 对齐（可含草稿）。
- 实现：服务端写出候选 URL 列表与无脚本回退 `href`；一小段客户端脚本在 `astro:page-load` 时从候选中重写 `href`。兼容 ClientRouter／View Transitions；无脚本时回退链仍可用。

### P4：列表页顶行与首页

- 文稿页（`ListView`，含标签页复用）在列表 UI **顶部**增加单独一行「随便逛逛」。
- **不参与分页**：不论当前页码或筛选，该行始终渲染在分页列表之上（位于分类头／筛选区之后、`[data-post-list]` 之前，且在 `[data-list-panel]` 内时随面板显隐；无标签选中时标签页面板隐藏则该行一并隐藏，避免空态噪音）。主文稿列表始终可见。
- 首页「近期笔墨」标题行右侧增加同一套「随便逛逛～」（与「全部文稿」并排）；候选为已发布文稿（`getPublishedBlogPosts`）。

### P5：UI

- **无边框按钮**：上一篇／随便逛逛／下一篇与正文链接一致——底边 `1px` 浅灰下划线，悬停改为强调色（同 `markdown.css` 的 `.prose a`），无描边胶囊、无填充底。
- **图标**：上一篇前缀 `<`，下一篇后缀 `>`；随便逛逛仅右侧装饰波浪 `随便逛逛～`（`aria-hidden`），详情／列表／首页一致。
- 邻接链接提供 `title`（篇名）便于悬停预览。

## 3. 权威表

| 事实 | 权威模块 | 不要 |
| --- | --- | --- |
| 排序 | `getSortedPosts`（`src/utils/data.ts`） | 在组件内另写排序 |
| 邻接与随机纯函数 | `src/utils/post-nav.ts` | 在 Astro 模板内手算下标 |
| 详情 UI | `src/components/blog/PostNav.astro` | 把按钮散落进 `RenderPost` 模板 |
| 列表顶行 | `src/components/blog/RandomBrowse.astro` + `ListView.astro` | 把随机行塞进分页 HTML |
| 首页入口 | `RecentWriting.astro` 复用 `RandomBrowse` | 另写一套随机逻辑 |
| 随机 `href` 重写 | `src/utils/post-nav-random.js` | 每页复制一份内联随机逻辑 |
| 文稿 URL | 与列表一致：`redirect \|\| withBasePath(\`/blogs/${id}/\`)` | 自造路径编码 |

## 4. 验收

- [ ] 降序夹具上：最新无上一篇、最旧无下一篇、中间双向正确；同日 `id` 并列次序与 `getSortedPosts` 一致。
- [ ] `pickRandomOther` 在排除当前后从不返回当前；候选为空时返回 `null`。
- [ ] 详情页：正文 → `cd ..` → 上下篇行 → 评论。
- [ ] 列表页：顶行不随分页消失；换页后仍在。
- [ ] 首页近期笔墨标题右侧有「随便逛逛～」，与全部文稿并排。
- [ ] 无 JS：随便逛逛仍有可点的回退链接；有 JS：每次 `astro:page-load` 可换候选。
- [ ] `pnpm` 相关 test／format／lint／check 子集通过。

## 5. 非目标

- 不按分类／标签限定随机范围。
- 不做「阅读历史」加权随机。
- 不改 RSS、归档时间线结构；首页仅在「近期笔墨」标题行增加随便逛逛，不改时间线条目。
