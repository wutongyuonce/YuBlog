# YuBlog 架构与实现

给后续开发用。改文案和数据走内容 skill；改行为先看本文件的**权威**和 **seam**，再动对应模块。Astro 语法见 [Astro.md](./Astro.md)，SEO 见 [Canonical URL、Sitemap、RSS.md](./Canonical%20URL、Sitemap、RSS.md)。

本文用这些词：

- **模块**：有界面、有实现的一块（函数、文件、页面拼装都可以）。
- **界面**：调用方必须知道的全部事实：签名、不变量、错误、配置、性能。
- **实现**：模块里面的代码。
- **seam**：界面所在的位置；可以在这里换实现、而不改调用方。
- **权威**：某类事实只允许在一处定义。别处只能读，不能再发明一份。

## 1. 这是什么站

Astro 5 静态站。主路径是**读文章**：首页列表、标签筛选、年份归档、文章详情。项目、关于、友链和前三者共用同一套索引壳（顶栏 + 主栏 + 右栏）。黑白主题，配置集中在 `src/config.ts`。

线上：`https://www.wutongyu.site/`。

构建：`pnpm build` → `dist/`（不进 git）→ `postbuild` 跑 Pagefind。

## 2. 页面地图

| 路由 | 人看到的 | 入口 | 数据权威 |
| :--- | :--- | :--- | :--- |
| `/` | 文章列表，七篇分页，可按分类筛 | `src/pages/index.mdx` | `blogs` 集合 |
| `/tags/` | 标签芯片；多选 AND；未选不列出文章 | `src/pages/tags.astro` | 同上，标签从文章 frontmatter 汇总 |
| `/archives/` | 按年时间线 | `src/pages/archives.astro` | 同上，按 `pubDate` 分组 |
| `/projects/` | 分类网格 | `src/pages/projects.mdx` | `src/content/projects/data.json` |
| `/about/` | 介绍 + Use / Hobby / Soul | `src/pages/about.mdx` | `src/content/about/*.md` |
| `/friends/` | 友链卡片 + 申请模板 | `src/pages/friends.mdx` | `src/content/friends/data.json` |
| `/blogs/[slug]/` | 正文、右侧 TOC | `src/pages/blogs/[...slug].astro` | 单篇 `blogs` |
| `/blogs/` | 旧入口，跳首页并保留查询串 | `src/pages/blogs/index.astro` | 无内容 |
| `/rss.xml` | 订阅源 | `src/pages/rss.xml.js` | 已发布 `blogs` |

顶栏文案和链接的权威是 `src/config.ts` 的 `UI.internalNavs` / `UI.socialLinks`，不是各个页面自己写死。

背景：首页 / 标签 / 归档 `dot`，项目 `rose`，友链 `snow`，关于关闭。权威是各页传给 `BaseLayout` 的 `bgType`。

## 3. 权威表（先看这里再改）

一类事实只应有一个主人。调用方从界面读，不要复制一份。

| 事实 | 权威 | 不要 |
| :--- | :--- | :--- |
| 站点 URL、标题、语言 | `src/config.ts` `SITE` | 在页面里写死域名 |
| 导航项、社交图标 | `src/config.ts` `UI` | 在 `NavBar` 里加死链接 |
| TOC / 搜索开关 | `src/config.ts` `FEATURES` | 在 TOC 组件里另做一套开关语义 |
| 文章字段合不合法 | `src/content/schema.ts` `postSchema` | 在页面里重新约定字段 |
| 已发布文章列表、排序、按年分组、名片统计 | `src/utils/data.ts` | 在视图里 `getCollection` 再 filter 一遍 |
| 查询串里的分类 / 标签 / 页码 | `src/utils/blog-browser.js` | 在 `ListView` 里手写 `URLSearchParams` |
| 右栏固定阈值与底部留白 | `src/utils/blog-sidebar.js` | 在布局脚本里重复计算滚动边界 |
| 标签 AND 匹配 | `src/utils/blog-tag-filter.js` | 在点击处理里写 `every`/`includes` |
| 路径是否带 `base`、是否补尾斜杠 | `src/utils/path.ts` | 字符串拼接 `/tags` |
| 顶栏、右栏、归档线、关于标签的跨页 CSS | `public/shell.css` | 只写在组件 `<style>` 里（ClientRouter 会丢） |
| 关于页标签集合 | `src/content/about/*.md` 的 `title`/`order`/`tab` | 在 `AboutView` 里写死三个名字 |
| 友链申请模板里的站名 / 链接 | `FriendsApplyPanel.astro` 里的 `friendInfo` | 和名片各写各的还不说明 |

`src/content/home` 仍在 `content.config.ts` 里注册，**当前页面不直接渲染 collection 条目**。不要把关于页文案写回 `home/index.md`。

## 4. Seam：该从哪切开

### 4.1 内容 seam

界面：Content Collections + Zod。  
实现：磁盘上的 md / json。  
调用方：`getCollection` / `getEntry` / `src/utils/data.ts`。

加一种新内容（例如新的关于标签）走集合，不要在 `.astro` 里写死数组。`about` 已经按文件扩展；新标签加一个 md 即可。

### 4.2 列表数据 seam

界面：`getFilteredPosts`、`getSortedPosts`、`getBlogListItems`、`getGroupedPostsByYear`、`getBlogStats`、`getRecentBlogPosts`。  
实现：草稿过滤、日期排序、渲染 `minutesRead`、按年 reduce。

首页、标签、归档、RSS、名片、近期文章都应穿过这里。测试也打这个界面（`test/blog-stats.test.mjs` 等）。

### 4.3 浏览器状态 seam

界面：`serializeBlogQuery` / 解析查询串（`blog-browser.js`）。  
实现：`category`、`tags[]`、`page`、每页 7 篇。

`ListView` 只负责把 DOM 和这个状态接上。改分页大小、改 AND/OR，改 `blog-browser.js` + 测试，不要改五处点击处理。

### 4.4 壳层样式 seam

界面：`public/shell.css` 的 class（`header.nav-bar`、`.blog-profile`、`.archive-*`、`.about-tabs`）。  
加载：`Head.astro` 里真正的 `<link rel="stylesheet">`。

**不变量**：硬刷新和 ClientRouter 看到同一份 CSS。Vite 注入的组件 `<style>` 在交换页面时可能消失。顶栏、右栏、归档、关于标签属于壳，放 `shell.css`。文章正文、友链卡片、TOC 内部仍可用组件样式。

### 4.5 布局 seam

- `BaseLayout`：文档头、背景、顶栏、主槽、页脚。不负责两栏。
- `BlogIndexLayout`：主栏 + 右栏。索引页的唯一两栏拼装处。
- `StandardLayout`：文章详情。

`BlogIndexLayout` 在宽屏下监听右栏尺寸和页面滚动：右栏先随主栏正常滚动，右栏底部到达预留间距后转为固定定位，主栏继续滚动；右栏尺寸变化时重新计算边界。窄屏直接恢复单栏流式布局。文章详情使用 `StandardLayout`，没有博客右栏，只共享固定顶栏。

新的「和首页一样带右栏」的页面：套 `BlogIndexLayout`，不要复制侧栏 JSX。

### 4.6 右栏内部 seam

`BlogSidebar` 只装配三块：名片、近期文章、分类，并为布局提供底部留白测量锚点；布局只依赖这个显式数据契约，不读取近期文章组件的内部 class。
名片统计的计算在 `data.ts`；进度数字在 `progress-stats.js`；近期五篇在 `getRecentBlogPosts`（**与主栏筛选无关**）。

### 4.7 TOC seam

`FEATURES.toc` 决定开不开、标题层级、左右。  
`TocSidebar` 负责高度（约 `66vh`）和滚动。  
固定显示的状态在 `DesktopAside`：点「TOC」toggle `data-pinned`，再点取消。不要把 pinned 写进 `config.ts`（那是运行时 UI 状态，不是站点配置）。

## 5. 运行链路

```text
src/content/*                 md / mdx / json
        ↓
src/content.config.ts         集合 + schema
        ↓
astro.config.ts + plugins/*   Markdown 管线（阅读时间、标题 id、外链…）
        ↓
src/pages/*                   路由
        ↓
layouts                      壳
        ↓
components/views             这一页怎么拼
        ↓
shell.css + src/styles       壳层 + 正文
```

`astro.config.ts` 里 `inlineStylesheets: 'never'`、`cssCodeSplit: false`，是为了硬刷新某一页时顶栏样式还在。不要为了「优化」改回去，除非同时解决 ClientRouter 丢样式。

## 7. 各页实现要点

### 首页 `/`

`ListView` 渲染全部文章节点，用查询串在浏览器里筛和分页。无 JS 时看到全部。选分类后出现「分类 / 名称 / 共 N 篇」。列表项 `ListItem`：文字约 60% + 图约 40%，图来自 `titleImage || cover`。

### 标签 `/tags/`

`TagFilter` 汇总标签。`ListView requireTags`：一篇不选则列表隐藏。排序（数量 / 名称）不得改已选集合。多选 AND，再点取消。防连点有 debounce。

### 归档 `/archives/`

`ArchiveView` ← `getGroupedPostsByYear`。点线 + 年份空心圆 + 文章小点。标题下划线跟文字走，不拉满格子。

### 项目 `/projects/`

`GroupView` ← `projects` JSON。`icon` 可选。分类字符串来自数据，组件不写死类名。

### 关于 `/about/`

`AboutView` 读 `about` 集合。`tab: false` 的是顶部介绍；其余按 `order` 当按钮。hash `#use` 可直达。关于页不要背景。

### 友链 `/friends/`

`FriendsView` 一张列表（不按 category 再分视觉大组，但仍有字段）。底部 `FriendsApplyPanel`：左说明、右 `friend.txt` 编辑器框。

### 文章 `/blogs/[slug]/`

`RenderPost` + 右侧 TOC。点 TOC 固定（加粗+下划线）。最高约页面 2/3，超出滚动。

## 9. 后续怎么加功能（按 seam 选点）

| 你想… | 动哪里 | 不要 |
| :--- | :--- | :--- |
| 新写一篇文章 | `src/content/blogs/`；正文图 `public/blogs/<名>-img/`；标题图 `public/blog-title-images/` | 改路由 |

| 全文进 RSS | `rss.xml.js` 或换 `@astrojs/rss` | 在 Head 里拼 XML |
