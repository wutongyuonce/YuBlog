# 旅行与日历

`/trips/` 是一张全屏地图，记录作者的旅行计划、已经走完的行程，以及带地点的日历记录；`/calendar/` 是按月浏览的日历视图。两页都不使用站点顶栏和页脚，左上角的作者胶囊回到博客首页，右上角有日历与地图的切换胶囊。顶栏在「归档」右侧直接放置「日历」与「旅行」两个入口。

行程来自圆周旅迹的分享链接，或由 AI 按作者提供的照片与信息整理成的草稿，都由同一个导入脚本转换成站内的中立数据后提交到仓库；日历记录手写在 `src/content/calendar/<id>/entry.md`。页面只读仓库数据，不在访问时请求圆周旅迹或路线服务。

## 旅行页 `/trips/`

**总览。** 面板顶部写「N 段旅程 · X 天 · Y 个地点 · 约 Z 公里」，标题「旅行」旁注明行程数据主要采集自圆周旅迹并做了适配，不逐条标出来源。旅程按开始日期倒序，按年份分组，每张卡片依次是封面拼图、标题、日期范围、「天数 · 地点数 · 约 N 公里」，以及「计划」或「记录」标记。地图同时画出全部旅程的路线、停靠点（同一段旅程内重复造访的同名地点合并为一个代表点，优先保留带照片的那次）和有地点的日历记录：

- **年份配色与筛选。** 有记录（旅程或带地点的日历条目）的年份从旧到新依次取调色板里的颜色；新增最新年份不会改变已有年份的颜色，补录更早年份时后面的颜色顺移。底部图例只列出有记录的年份；默认显示全部年份，点击某一年只看这一年的路线、点和列表分组，再点一次回到全部，筛选状态写进 `?year=`。飞机路线用粗虚线，其余路线用实线。
- **照片标记与叠片聚合。** 每个停靠点和每条带地点的日历记录优先用第一张照片做方形缩略图（带白框与右下角年份色点），没有照片时退回彩色圆点。按当前整数缩放级别在屏幕空间做确定性聚合（有照片的点优先作为封面种子），两个及以上邻近点合并成三张扇形叠片加右上角数量角标；点击叠片平滑放大并框住其全部成员，已到最大聚合层级或坐标重合时直接打开对应详情。

**状态。** 以 `Asia/Shanghai` 的当天为准：结束日已过的旅程标为「记录」，否则为「计划」。构建时先按构建日期渲染一次，浏览器再按访问当天重算，页面不需要因为日期变化而重新部署。

**选中旅程。** 点击卡片、地图上的路线或停靠点，打开这段旅程的详情，地址变为 `/trips/#<id>`，可以分享，浏览器的后退回到总览。详情包括：

- 封面拼图和三个数字：天数、地点数、全程公里数（由各天里程相加得出）。
- 「回放行程」按钮。
- 按天列出的日程：每一天标题右侧显示当天里程（从这一天出发的路段之和，跨天路段归出发那天），停靠点序号每天重新从 1 开始；每站展示分类图标、名称、时间段、备注、照片和「小红书 ↗」搜索入口。只有开始或结束时间时写成「22:00 起」或「至 00:25」。两站之间单独一行展示交通方式图标、班次号与起止时刻（或公交线路与票价）、时长和公里数；路线服务降级为直线时标明「直线约 N 公里」。

选中后地图缩放到这段旅程，停靠点显示当天序号。**面板滚动联动地图**：停在顶部封面与统计处时看整段旅程；向下滚入各天日程时（阅读偏移在最后一屏自动追平到末尾，确保最后一天与最后一站完整触发），地图框住当前天，当天路线高亮、其他天路线变淡、其他天的点隐藏，当前站放大并在下方显示名称胶囊，同时在路线上实时移动带当前交通方式图标和「日期／第 N 天时刻」胶囊的线头。照片点击后用对话框放大，可在同一段旅程内前后翻看。

**选中日历记录。** 点击地图上的日历标记，或从日历页点击某条记录标题右侧的地点跳到 `/trips/#calendar/<id>`，地图飞到该地点，右侧面板展开这条记录的完整内容，并附回该月日历的链接。

**回放。** 至少有两个停靠点的旅程才能回放。回放时面板收起，地图沿路线逐段画线并标出已到达与未到达的停靠点，线上移动的是当前交通方式的圆形图标徽章与右侧「日期／第 N 天时刻」胶囊，到站时在站点下方显示名称胶囊，镜头跟随；换到新的一天时先展示当天标题和里程。左下角回放卡片（窄屏在底部）：

- **进度条。** 顶部按站分段，实时显示播放进度，悬停提示站名，点击任意一段直接跳到该站。
- **媒体区。** 竖屏视口下 3 张以内直接排开，横屏视口下 9 张以内按网格排开（1 张 4:3、2 或 4 张两列、其余三列九宫格）；超过上限时改为上方一张大图、下方缩略图条，每张按 `1.5 秒 ÷ 倍速` 自动轮播，路上移动时也继续切换，点击缩略图可手动切图，点击大图或网格照片打开照片对话框。到站停留时间取「3 秒」与「照片数 × 1.5 秒」中的较长者。
- **控制栏。** 上一站、播放／暂停、下一站、`1x / 1.5x / 2x` 倍速（保存在 `localStorage` 的 `trips-replay-speed`）和退出。支持键盘左右方向键切站、Esc 退出。系统开启「减少动态效果」时不播放线条和镜头动画，只逐站切换。

**地图设置。** 工具栏的图层按钮打开设置面板，可选底图风格（跟随主题、彩色、明亮、浅灰、深色、深蓝）和「3D 视角」开关（打开时随缩放倾斜并在 14 级以上显示立体楼块，默认跟随主题、打开 3D，保存在 `trips-map-settings`）。

**降级。** 没有 JavaScript 时，面板以静态列表呈现，卡片通过 `#<id>` 锚点用 `:target` 展开详情。地图加载失败时显示原因，回放停用，列表、详情和照片照常可用。

## 日历页 `/calendar/`

`/calendar/` 直接渲染最近一个有记录的月份，每个有记录的月份同时生成静态页 `/calendar/<年>/<月>/`。

- **顶栏。** 左侧作者胶囊回首页，中间是上月／下月箭头与年月选择器（按有记录的年份列出 1–12 月 6 列网格，有记录的月份高亮可点），右侧是与旅行页同位置的日历／地图切换胶囊。
- **宽屏月视图（> 896px）。** 周一开头，填满整周，左上角显示双位等宽日期数字（`01`–`31`）；有照片的日期格展示首张照片、标题标签与额外照片／记录数 `+N`，纯文字记录格展示圆点与条数。点击格子在右侧滑出抽屉（顶栏与月历同步左移保持对齐），展示整月时间线（新的在前）并平滑滚动、高亮所点记录，地址同步为 `#<id>`；再点一次、点关闭按钮或按 Esc 收起抽屉。
- **窄屏时间线（≤ 896px）。** 隐藏月格，顶部固定有记录日期的快捷定位条，下方直接展示当月时间线。
- **记录条目。** 标题右侧若有地点，显示图钉与地点名，点击跳转到 `/trips/#calendar/<id>` 在旅行地图上定位并展开这条记录；下方是时间、照片网格（1 张自适应比例、2 张两列、3 张首图跨两行、4 张四宫格，点击打开照片对话框）和 Markdown 正文，允许只写文字不放图片。

## 数据

### 旅程 `src/content/trips/<id>/trip.json`

字段契约以 `src/content/schema.ts` 的 `tripSchema` 为准：

```jsonc
{
  "title": "重庆市3日游",
  "start": "2026-11-06",
  "end": "2026-11-08",
  "cover": ["./cover-1.jpg"],        // 兜底封面，按优先级排列，可为空
  "days": [
    {
      "date": "2026-11-06",
      "summary": "SPA·全季·绿心·西南", // 可选
      "stops": [
        {
          "name": "绿心公园",
          "category": "景点",           // 可选
          "emoji": "⛲️",               // 可选
          "address": "…",              // 可选
          "coordinates": [106.53, 29.6], // WGS84，[经度, 纬度]
          "time": { "start": "11:00", "end": "16:00" }, // 可选，任一端可省
          "note": "…",                 // 可选
          "photos": ["./s01-1.jpg", "./s01-2.webp"],
          "route": {                   // 去下一站，最后一站没有
            "mode": "taxi",            // flight / train / ferry / taxi / drive / walk / bike / transit
            "distance": 6200,          // 米
            "duration": 900,           // 秒，可选
            "straight": true,          // 可选，路线服务降级为直线时标记
            "service": {               // 可选，仅 flight / train / ferry
              "number": "PN6458",
              "depart": "22:00",
              "arrive": "00:25"
            },
            "transit": {               // 可选，仅 transit
              "fare": "7元",
              "lines": [{ "name": "轨道交通9号线(溉澜溪→中央公园东)" }]
            },
            "path": [[106.53, 29.6], …]
          }
        }
      ]
    }
  ]
}
```

- **中立性。** 不保存圆周旅迹的行程 ID、分享链接、用户 ID、昵称或头像。
- **路线与交通方式。** 共八种：`flight`、`train`、`ferry`、`taxi`、`drive`、`walk`、`bike`、`transit`。班次类（飞机、火车、船）可带 `service`，路径为两点直线；公共交通可带 `transit` 线路明细与票价；路线服务失败退回两点直线时保留原 `mode` 并标记 `straight: true`，不再把「直线」当作一种交通方式。未显式设置交通方式时按两站大圆距离自动推断：1.5 公里以内 `walk`，超过 1.5 公里 `drive`。
- **图片与动图。** 导入时静态图长边缩到 1280px 以内、转成质量 80 的 JPEG；GIF 动图保留全部帧，转成带动画的 WebP；构建时 Astro 输出的 WebP 同样保留动画帧。

### 日历 `src/content/calendar/<id>/entry.md`

每条记录一个目录，目录名即 `id`，图片放同目录，字段契约见 `calendarSchema`：

```markdown
---
title: 南京博物院
date: 2026-11-12
time: '14:30'
place:
  name: 南京博物院
  coordinates: [118.8253, 32.0414]
photos:
  - ./museum-1.jpg
---

正文写 Markdown，也可以只有文字、不放 `title`、`photos` 或 `place`。
```

## 导入与照片脚本

```bash
pnpm trips:import '<圆周旅迹分享链接或行程 ID>' [--id <站内 id>] [--check]
pnpm trips:import --from <草稿.json> [--id <站内 id>] [--check]
pnpm trips:photos <照片或目录>... [--geocode]
```

1. **分类校验与 `--check`。** 适配器与草稿解析器把发现的问题分成三类：`source`（圆周旅迹出现了未映射的事件类型、交通编码或坐标系，需更新 `src/utils/pitravel.mjs`）、`schema`（超出本站 `tripSchema` 的能力，如视频素材，需讨论是否扩展 schema）、`data`（个别条目缺坐标等，已跳过或降级并警告）。`--check` 只拉取、转换并用同一份 `tripSchema` 校验，不请求 Valhalla、不下载图片、不写盘；出现 `source` 或 `schema` 问题时退出码为 1。正式落盘前同样先过一遍 `tripSchema`。
2. **圆周旅迹适配（`src/utils/pitravel.mjs`）。** 请求 `journey/detail` 取行程，再按相邻两站的 `inner_poi_id` 与 `route_transportation_type`（0 开车、1 步行、2 骑行、3 公共交通、5 打车；缺省或跨天未设置时按 1.5 公里阈值推断步行或开车）请求 `POST /api/slytherin/v1/web/route`，拿到国内路网的距离、时长、GCJ-02 路径（转 WGS84）以及公共交通的线路名与票价；200–208 交通事件拆成出发和到达两个交通节点，班次号与起止时刻写进两站之间的 `service`。遇到未知的事件类型、交通编码或坐标系直接报告 `source` 问题，不再静默当成直线。
3. **路线回退（`src/utils/trip-routes.mjs`）。** 优先用圆周路线接口给出的路径与距离；没有或失败时，打车、开车、步行、骑行退回公共 Valhalla（`auto`／`pedestrian`／`bicycle`），仍失败或其余方式退回两点大圆直线并标 `straight: true`。
4. **照片 EXIF 读取（`scripts/read-photos.mjs`、`src/utils/photo-exif.mjs`）。** 从 JPEG、PNG、WebP、GIF、HEIC／HEIF 读取宽高、是否多帧动图、EXIF 拍摄时间与时区、GPS 坐标（WGS84），按日期及时间间隔（> 90 分钟）或距离（> 500 米）聚成候选地点，`--geocode` 时用 Nominatim 反查名称与地址，供内容发布 skill 引导作者手动整理行程或日历。

```bash
node --test test/pitravel.test.mjs test/trip-draft.test.mjs test/trip-routes.test.mjs test/trips.test.mjs test/trip-replay.test.mjs test/trip-map-settings.test.mjs test/calendar.test.mjs test/photo-exif.test.mjs test/content-schema.test.mjs
```

- `trips.test.mjs`：每日与全程里程、动态年份配色、按天重新编号、路段文案、拼图兜底、滚动阅读偏移。

- `calendar.test.mjs`：周一开头月格、有记录月份、1–12 月选择器分组、时间线排序。
- `photo-exif.test.mjs`：JPEG／WebP／GIF 的 EXIF 时间、GPS、动图识别与候选地点聚类。
