# 分支更新报告：feat/blog-ux-and-performance-overhaul

本文是 PR 描述材料，记录本分支相对 `main` 的全部改动。分支原名 `codex/enlarge-blog-card-images`，现已超出原范围，故改名。

**快照**：`HEAD = 59fceeb`（与 `main` 同一提交），改动全部在工作区，共 483 个状态条目：401 个重命名（图片搬迁）、70 个修改、9 个新增、2 个删除、1 个重命名兼修改。

改动来自多个会话：Codex 的「缩窄博客整体排版宽度」、Pi 的「首页卡片图片调整」「右侧 TOC 改版」「关于页四个按钮」、以及一次全站 UI／排版／性能审计与其修复。

---

## 1. 版心、首页卡片与列表

- 桌面索引版心 858px → **904px**（主栏 648px、栏距 44px、右栏 212px），顶栏共用同一版心。
- 首页有图卡片文字／图片列比改为 **15:11**，图片在 ≥768px 用 `align-self: center` 行内居中；卡片高度仍由内容决定。
- 卡片分隔线从「卡片自身 `border-bottom`」改为「每个可见项 `border-top`」，最后一张卡后不再拖一条线。
- `ListItem` 去掉了字符串图片分支，统一走 `<Image>`。

## 2. 顶栏

- 导航高亮改为滑动指示条 `.nav-bar__indicator`：按 `aria-current="page"` 计算位置与宽度，`/blogs/*` 归到首页项，`resize` 与 `document.fonts.ready` 时重新定位（不播动画），无匹配时宽度归零隐藏；监听器用 `documentElement.dataset` 只绑一次。
- `.nav-bar__pages` 加 `transition:persist`，换页时指示条不重建。
- 顶栏高度 56px → **48px**，垂直内边距 0.375rem → 0.25rem。
- 窄屏（≤600px）隐藏站名，导航从三行收成两行。

## 3. 文章目录（TOC）

- 交互语义重做：`data-pinned` → **`data-open`**，触发器 `aria-pressed` → **`aria-expanded`**，`title` 在「显示目录／隐藏目录」间切换，关闭时用 `visibility` 而非 `opacity` 隐藏（因此关闭状态下不会再被 Tab 聚焦）。
- 去掉 `displayMode`（hover/content/always 三种显示档位）；`FEATURES.toc` 不再接受 `displayMode`。
- 当前章节判定从 `IntersectionObserver` 改为 rAF 节流的滚动／尺寸处理，调用新抽取的纯函数 `src/utils/toc-active.js` 的 `pickActiveHeadingIndex()`；激活线取标题的 `scrollMarginTop`，到页面底部时最后一个标题胜出，并用 `ResizeObserver` 监听 `<body>` 以覆盖懒加载图片／字体造成的位移。
- `<Toc>` 不再接收 `isArticle`，也不按层级过滤（改由 `[data-toc-link]` 与文档顺序决定）。
- `DesktopAside` 打开时派发冒泡的 `toc-reveal`，TOC 侧收到后把当前项滚入视野居中（尊重 `prefers-reduced-motion`）。
- 移动端目录：点击链接后收起，并支持 Escape 关闭、焦点还给开关。
- 文章锚点跳转不再被固定顶栏遮住（按实际顶栏高度设置 `scroll-margin-top`）。

## 4. 关于页

- 顶部正文并入标签栏，成为四个按钮 **About / Use / Hobby / Soul**，About（`order: 0`）默认选中；`intro.md` 改名 `about.md` 并去掉 `tab: false`。
- 标签栏加滑动指示条 `.about-tabs__indicator`。

## 5. 分页与标签页

- `getPageNumbers` 改为固定 ≤6 槽窗口：`1 2 3 4 … N`、`1 … N-3 N-2 N-1 N`、其余 `1 … p p+1 … N`，端点与当前页始终可见；省略号表示至少跳过 2 页。
- 分页样式从 `ListView` 组件移到 `public/shell.css`，上／下一页改成 `‹`／`›` 字形（`aria-hidden`）配 `aria-label="上一页/下一页"`。
- 标签排序改为两格滑动胶囊；清空已选标签后焦点落到第一个标签按钮，不再掉到 `body`。

## 6. 性能

- **字体子集化**：文章标题的霞鹜文楷从每篇加载 7.65 MB 降到 **73 KiB**（404 页手写体 6.8 MB → 66 KiB）。`scripts/font-subset.mjs` 在 `postbuild` 里按实际渲染字符生成子集，`@font-face` 先子集后全量（子集缺失时自动回退）。
- **图片管线迁移**：内容图片从 `public/` 搬进 `src/content/`，改用相对路径 + 图片管线（自动 WebP、`srcset`、宽高、懒加载）。新增宽度标记插件（alt 后缀 `|w353`）与封面 `image()` 字段。文章页图片下载量实测下降 90–96%（例：算法 3 16.54 MB → 0.64 MB），首页图片 6.1 MB → 633 KiB，`public/` 图片从 101.1 MiB 降到 0.7 MiB。
- 文章 `og:image` 改为构建时生成的 1200px JPEG，不再直接指向 4K 原图。
- **KaTeX 本地化**：样式从 jsDelivr CDN（锁 0.16.11）改为本地 `katex` 包（与渲染器 0.16.45 一致），并由 PostCSS 插件只保留 woff2 源（省约 800 KiB 产物）。全站只有 1 篇带公式的文章会真的取字体。
- **Pagefind 按需加载**：只有打开搜索面板时才拉 `pagefind.js` 与 worker（约 35 KB）；`pagefind-highlight.js` 只在带 `?search=` 的页面加载。
- **背景动画**：点阵背景每帧的 `stroke` 次数从 6076 降到 **6**（按透明度分档批量描边），每帧 JS 从约 5ms 降到 0.42ms；点数上限 8000（4K 屏从 37668 点降到 8349）；canvas 后备存储 DPR 上限抽到 `src/utils/canvas-size.js` 共用。

## 7. 无障碍与 SEO

- 点阵／雪花背景响应 `prefers-reduced-motion`：只画一帧静态背景，并在系统设置变化时启停。
- 搜索面板的 `aria-modal` 声明成真：Tab 在面板内循环；结果项带 `aria-activedescendant` 供读屏器跟踪；Escape／点遮罩关闭并把焦点还给搜索按钮。
- JSON-LD 修正：`webPage` → `WebPage`，`publisher` 由 `ProfilePage` 改为 `Person`。
- 标签页补充 `aria-pressed` 与焦点可见样式。

## 11. 影响面与风险

- **URL 不变**：文章路径、slug 生成方式均未改动。旧图片地址（`/blogs/<名>-img/…`、`/blog-title-images/…`、`/about/<栏>/…`）不再部署，会 404；仓库内除文档外无代码引用它们。
- **构建依赖**：`postbuild` 现在必须先跑 `scripts/font-subset.mjs`；跳过它会让 CSS 的第一个 `src` 404 并回退到 7.65 MB 全量字体。
- **仓库体积**：源图仍保留原始分辨率（未降采样），`dist` 从 198 MB 降到约 107 MB。
- **待办**：三个新 util 已有 `test:*` 专用脚本；`docs/项目解析.md` 的 `data-pinned` 段落已改为 `data-open`/`aria-expanded`；`|w70x` 与 SPEC 阈值的矛盾已按实现修正 SPEC 文字。
- **待确认（需要作者定）**：TOC 的 `displayMode` 档位（hover/always/content）已删除，改成手动点「目录」开关；这与最初「保留原有自动隐藏」的要求有出入。
