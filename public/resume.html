Pai· 本地长程任务 Coding Harness
github.com/wutongyuonce/Pai
背景基于 pi 和 pi-durable 构建的本地长程任务 Coding Harness，解决缓存失效、上下文膨胀、失忆与中断恢复。

  1. Provider SDK 层：统一 Model/Message/Tool，屏蔽协议差异；实现异步事件流 EventStream，以「事件队列 + Future 挂起/唤醒」实现生产者（provider）和消费者（如工具执行）的解耦，向上层交付 text / thinking / toolcall 三类增量事件；

  2. 双层 Agent Loop Runtime 层：

    1. 内层完成模型与工具的多轮交互，并在下一轮处理 Steering，外层接续 Follow-up；
    2. 基于全链路生命周期 Event 和 Control Hook 构建 Middleware 插件，统一承接上下文改写、工具拦截与执行追踪；

  3. 面向长程任务的 Coding Harness 层：

    1. 缓存复用，保持前缀稳定：支持缓存保温，在缓存 TTL 内发送最小请求避免过期；以追加配置事件切换思考档位，适配 GPT-6 configuration_update；支持 tool_search 按需动态加载工具；

    2. 上下文治理：大型工具结果卸载为本地快照，上下文仅保留可取回引用；分级 Checkpoint 压缩机制，增量提取 Observation 与 Reflection，避免 Compaction 一次性重读全部历史；

    3. 崩溃恢复机制：将 Agent Loop 拆解为可持久化的任务树与 Durable 状态机，崩溃恢复时由调度器按幂等性重放或补写中断结果，实现可靠续跑；

    4. 5.

      Subagent 和 Code Mode：/task 分派受限子代理，支持追加指令、终止和查状态；JS agent()、parallel()、pipeline() 编排工作流；QuickJS 沙箱批量调用工具并隔离中间结果；

    5. 6.

      跨会话长期记忆：按项目/全局保存可检索事实、经验和流程；后台 /dream 整理去重，/distill 提炼 Skill；

    6. 7.

      安全与沙箱：支持工具白名单和 YOLO、人工审批和自动审批三种模式，Guardrails 拦截 bash 危险命令，系统级 Bash 沙箱限制可达文件、网络和进程访问；

  4. Agent Trace & Eval：

    1. Langfuse 关联任务、模型轮次、工具调用和压缩，追踪耗时、Token、缓存、成本与失败原因；

Trajex· 面向 Agent 的本地会话记忆 Infra
github.com/wutongyuonce/Trajex · 127⭐
背景面向 Claude Code/Codex/Pi，规范化 JSONL Traces 后写入 SQLite，供 Agent 和用户跨会话检索与回溯。
技术栈TypeScript、Node.js 22、SQLite/FTS5、Electron、Vue 3、chokidar、Worker Thread
  1. 统一会话处理 Pipeline：
    • Provider Adapter 将 Pi 树状会话、Claude Workflow 等日志统一为 Record，隔离 Provider 差异；
    • 持久化层只处理通用记录，解耦 Provider 差异与索引，便于扩展新 Provider；
  2. 本地证据层：基于 SQLite + FTS5 拆分 sessions/messages/tool calls/workflows/memories 等表，支持多场景、跨会话回溯；
  3. Agent 与用户侧双入口：
    • Agent 侧通过 Trajex CLI + Skill 在 node:vm 沙箱运行 JS Query API (search/memories/...) 脚本，实现毫秒级查询；
    • 用户侧 Electron App 展示会话、对话详情、Memory 和 Activity；
  4. 4.跨进程安全的索引写入：
    • heartbeat 软所有权 + SQLite writer lease 硬互斥，协调 App/CLI 写入；
    • BEGIN IMMEDIATE → COMMIT/ROLLBACK、upsert 和稳定主键保证写入原子性、幂等性与数据一致性；
  5. 5.覆盖三类场景的 Benchmark Eval：
    • 长期交互记忆 LongMemEval 主动检索 rubric 正确率 91.6% (无记忆 31.2%、纯向量 RAG 81%)，且相比 full arm 输入 token 降 88.9%、延迟降 63.4%；
    • 跨会话记忆 LoCoMo multi-hop QA F1-score 达 66.5% 接近 SOTA (无记忆 26.8%、RAG 60.5%)；
    • 失败经验重试 SWE Bench Retry grader 通过率 55.6% (无记忆 29.3%、RAG 45.2%)。
